# 图书学习记录管理仓库

这个仓库用于管理个人的图书阅读、学习笔记和总结资料，适合用于记录每本书的阅读进度、核心内容和学习收获。

## 目录说明

- books/：存放图书资料、阅读清单或书籍相关文件。
  - books/重构-改善既有代码设计-第二版/：已导入《重构：改善既有代码设计（第二版）》书籍内容。
- notes/：存放阅读笔记、重点摘录和思考记录。
- summaries/：存放每本书的阅读总结或学习复盘。
- templates/：存放可复用的模板文件。
- archive/：存放已完成或不再更新的内容。

## 使用方式

1. 在 books/ 中新增或整理图书信息。
2. 在 notes/ 中记录阅读过程中的重点内容和想法。
3. 在 summaries/ 中撰写阅读总结或学习成果。
4. 使用 templates/book-template.md 快速创建新的书籍记录。

## 推荐工作流

- 先建立阅读目标
- 阅读过程中记录笔记
- 完成后生成一份总结
- 将旧内容归档到 archive/

可以从 templates/book-template.md 开始创建新的图书记录。
